# 기술 결정 기록

설계·기술 결정을 한 파일에 하나씩 남긴다. "왜 지금 코드가 이렇게 생겼는가"에 답하는 문서.
장애·버그는 여기가 아니라 [../incidents.md](../incidents.md)에 적는다. 장애를 계기로 구조를 바꿨다면 장애는 incidents.md에, 바꾼 구조와 그 이유는 여기에 적고 서로 링크한다.

파일명: `YYYY-MM-DD-짧은-제목.md`

## 템플릿

```markdown
# 제목

- 날짜:
- 상태: 채택 / 대체됨(→ 새 결정 링크) / 폐기
- 관련 커밋/PR:

## 상황
## 고려한 선택지
## 결정과 이유
## 결과 (수치)
## 다시 검토할 조건
```
